Investment Live Private Backups

A personal-use tool for keeping encrypted copies of the owner's investment-system database in the owner's private Google Drive storage.

Production backup access is being prepared. This information website does not start a backup, offer a sign-in service, or give access to any investment data.

Purpose and planned operation

  1. An owner-authorized cloud workflow exports database data using a dedicated backup identity.
  2. The workflow encrypts the export with an age public key and checks the encrypted file and its manifest.
  3. After owner approval and acceptance testing, encrypted files and non-secret integrity manifests are stored in a private Drive destination.

The decryption private key is retained by the owner outside the cloud backup runner. Database export and restore coverage have to be checked separately; this tool is not a complete backup of all cloud-platform services.

Google Drive permission

The application requests only the Google Drive drive.file permission. This permits access to files created by the application or explicitly selected for it by the owner, not unrestricted access to all Drive files.

The permission can allow reading, creating, updating, and deleting those authorized files. Backup retention cleanup is subject to separate backup-validity checks. The application does not request access to Gmail, contacts, or calendars.

Owner control

This is not a public backup service. Only the configured owner account is accepted by the enrollment helper. The owner controls authorization, the private storage destination, and whether production schedules are enabled.

Read the privacy notice and use terms before authorizing the tool. Authorization can be revoked in the Google Account connections settings.
