Investment Live Private Backups

Privacy Notice

This notice describes the personal-use backup tool and its planned production operation. Production authorization and backup acceptance are separate from publishing this notice.

Data accessed and purpose

  • The owner's Google account email is checked through Drive account metadata to prevent enrollment of an unintended account.
  • Drive files and metadata accessible under drive.file are used only for owner-authorized backup storage, download verification, health checks, and retention management.
  • Encrypted backup contents and integrity manifests may contain personal financial data or metadata. They remain private and are not published on this website.

The tool does not request unrestricted Drive access, Gmail access, contacts, or calendars. Google Drive market or investment data is not used to train models, for advertising, or for profiling.

Storage and security

OAuth enrollment credentials are held in the owner's protected local directory. When separately approved, only the credentials needed for cloud operation are configured in GitHub Secrets. OAuth access tokens are short-lived and must not be written to logs or public files.

Backups are encrypted before uploading to Google Drive. The age decryption private key is not stored in the cloud runner, GitHub Secrets, this public repository, or the backup Drive directory. Public encryption keys are not decryption keys.

Production backup temporary data requires restricted access and cleanup. No password, OAuth token, unencrypted export, private key, destination identifier, or backup implementation is published on this site.

Sharing and service providers

No Google user data is sold, shared for advertising, or provided to model services. Google processes the authorized Drive operations. GitHub provides the separately authorized cloud execution and secret storage. Access is restricted to the owner and the service providers needed to operate the backup.

Use of Google API data follows the Google API Services User Data Policy, including its applicable Limited Use requirements.

Retention and removal

The planned backup retention is 14 daily, 8 weekly, and 6 monthly recovery points. Automated deletion will not be enabled until separately accepted safeguards require a recent valid backup to remain. Retained backups can still contain historical data until the owner deletes or expires them.

The owner can remove application-accessible Drive files and revoke access in Google Account connections. Revocation stops future API access; it does not automatically delete existing encrypted backups or local credential files. Cloud credentials must also be removed to retire the tool.

This information website

The pages have no application analytics, tracking scripts, forms, account sign-in, or advertising. GitHub Pages, as the hosting provider, may record visitor network information under the GitHub Privacy Statement.
